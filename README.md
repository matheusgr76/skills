# Skills

Reusable coding-agent skills. Each skill lives in its own folder with a `SKILL.md` and any supporting files.

## AASDP

[`aasdp/`](aasdp/) is the AI-Assisted Software Development Protocol skill. It guides project discovery, lean documentation, approved phases, verification, and completion.

To use it across projects, copy the complete `aasdp` folder to:

- Codex: `~/.agents/skills/aasdp/` (invoke `$aasdp`)
- Claude Code: `~/.claude/skills/aasdp/` (invoke `/aasdp`)

For one repository, copy it to that repository's `.agents/skills/aasdp/` for Codex or `.claude/skills/aasdp/` for Claude Code. Keep `references/` with `SKILL.md`.
